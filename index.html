API keys

Add up to 2 Gemini keys (free: aistudio.google.com/apikey) and 1 Bolt key (free: console.groq.com/keys). Gemini requests rotate between your Gemini keys and skip any that fail or hit limits. The Bolt key powers the Coolkid Bolt models (model menu → More models). Coolkid 4 Argon can work on a free key. Some Pro-class models (3.8, 3.7, 3.6, 3.1 Pro) need a key with billing turned on; if your key does not allow a model, it automatically uses a Flash model instead. Web search runs through Google Search on the same key.
